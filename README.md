# Sistema de Caixa Eletrônico

Projeto desenvolvido em Java 17 e Swing.

## Executar

Abra o projeto no IntelliJ IDEA e execute `src/Main.java`.

Conta disponível para teste:

- `123456` - saldo de R$ 5.000,00

O sistema permite realizar saques, sacar o valor máximo disponível, escolher a estratégia de composição das cédulas e administrar o estoque do caixa. As operações são registradas em `registros/eventos-caixa.txt`.
